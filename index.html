Mengenal Komponen Komputer

Belajar fungsi dan bagian-bagian komputer

Processor (CPU)

Berfungsi mengolah data dan menjalankan perintah komputer.

RAM

Menyimpan data sementara ketika komputer digunakan.

Harddisk / SSD

Menyimpan data dan file secara permanen.

Motherboard

Menghubungkan seluruh komponen komputer.

Monitor

Menampilkan gambar dan informasi dari komputer.

Keyboard

Memasukkan huruf, angka, dan perintah.

Mouse

Menggerakkan pointer dan memilih objek.

Power Supply

Menyalurkan daya listrik ke komponen komputer.
